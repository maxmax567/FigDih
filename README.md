## ✨ Características

- 🔐 **Auth con Argon2** — contraseñas hasheadas
- 🏠 **Múltiples servidores** con canales
- 👑 **Roles** (Owner/Admin/Mod/Member) y moderación completa
- 💾 **SQLite** con persistencia
- 🎨 **8 temas** + notificaciones + emojis
- 🐳 **Docker** + WebSocket cifrado
